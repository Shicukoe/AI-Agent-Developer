Repos / Dự án

Mỗi board Trello được gắn với một repo. Card nằm trên board nào thì task chạy trên repo đó.

Thêm dự án mới

Tạo board Trello và lấy board ID, clone repo cần xử lý về máy đang chạy agent, rồi điền thông tin bên dưới và bấm Lưu. Khi lưu, các list và nhãn còn thiếu sẽ được tạo trên board.

Nhánh gốc để tạo nhánh feature và so sánh thay đổi.
Các repo agent được đọc để tham khảo khi task liên quan tới code nằm ở repo khác. Code chỉ được ghi vào repo chính.
